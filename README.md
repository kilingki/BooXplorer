# BooXplorer

BooXplorer는 도서를 발견하고 비교해 읽거나 구매할 책을 고르는 과정을 돕는 로컬 AI 서비스다. 서점에서 관심 분야의 책장을 찾고 주변 책을 살펴보듯, 사용자가 제목이나 존재를 몰랐던 책까지 탐색해 자신의 학습 목적에 맞는 책을 고를 수 있게 한다.

## 주요 기능

- **자연어 도서 탐색** — 주제, 출판 시기, 난이도, 목적, 언어를 반영해 검색 질의를 구성하고, 웹에서 실제 존재가 확인되는 후보를 찾아 관련성과 근거의 신뢰도로 정렬한다.
- **유사 도서 탐색** — 기준 도서의 목차, 내용, 주제가 의미상 유사한 책을 찾는다.
- **도서 정보 수집 및 확장 분석** — 합법적으로 접근할 수 있는 도서 정보와 자료를 통합한다. 실제 도서에서 확인한 내용과 외부 자료 및 모델 추론으로 보강한 설명은 구분해 제시한다.
- **도서 비교** — 주제와 범위, 깊이와 난이도, 내용의 중복과 차이, 독서 목적에 대한 적합성, 독서 우선순위를 비교한다.
- **개인 책장** — 책을 저장·분류하고 태그를 관리하며, 검색과 필터링, 분석 결과 조회, 연관 도서 탐색, 저장한 도서 간 비교를 지원한다.

## 예상 서비스 형태

로컬 PC에서 독립적으로 실행하며, PC와 스마트폰의 웹 브라우저에서 모든 핵심 기능을 제공한다. Local-first, Mobile-first, File-first를 기본으로 하고 외부 접근에는 Tailscale을 사용한다. 도서 정보와 분석 결과는 파일 저장을 우선하며 Markdown과 HTML을 후보로 고려한다.

프론트엔드 개발 단계에서 VoXtract와 ArXtract의 PWA 구조, UI/UX, 레이아웃, 컴포넌트, 모바일 대응, 서버 통신을 검토하고 재활용할 부분을 결정한다.

## 외부 기술 의존성

| 외부 구성 요소 | 역할 |
| --- | --- |
| Web Search / Extraction Module | 선행 개발 대상. 웹 검색, 페이지 접근·렌더링, 콘텐츠 추출, 원본 URL과 출처 관리를 담당한다. |
| Embedding / Reranking Runtime | 선행 개발 대상. 임베딩과 의미적 유사도 계산, 검색 후보의 관련성 평가와 재정렬을 담당한다. |
| LLM Runtime | 검색 의도 분석과 질의 생성, 정보 구조화, 관련성 평가, 도서 분석과 비교에 사용한다. 기존 로컬 LLM 런타임 및 InferSwap 활용을 우선한다. |
