# BooXplorer

BooXplorer is a local-first AI project for discovering books through natural-language requests. Describe what you want to learn and how you want to learn it, even if you do not know a book's title.

> Find a beginner-friendly book in Korean that explains probability through everyday examples.

## Development status

The prototype ranks books from saved bookstore search results against the original request and retains edition details and source links. Live bookstore search is still in development.
